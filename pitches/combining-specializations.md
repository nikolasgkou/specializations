# Can I do two specializations? Combining branches

You can complete **two** specializations — but the timing only works one way:

> **To do two, you must start your first branch in Wave 1 (18 June).** Starting in September leaves no room for a second one. Email your two top choices by **Tuesday 16 June**.

**Any two branches can be combined.** A second branch goes *faster* when it shares tools and skills with your first — you reuse what you already learned instead of starting from zero. The matrix below shows how much skill overlap each pair has. More overlap means a quicker, smoother second branch — **not** that a combination is better or worse. Pick by interest first; use the matrix to know what to expect.

## Why the strongest overlaps work (●●●)

- **Cloud DevOps + Java Full-Stack** — Java already uses Docker, Jenkins, Nexus and SonarQube; DevOps deepens it with Kubernetes, Terraform and cloud.
- **Cloud DevOps + Artificial Intelligence** — shared Python and containers; DevOps gives you the infrastructure to serve and scale ML models (MLOps).
- **Cloud DevOps + Cybersecurity** — shared Linux, networking and virtual machines; offensive testing on top of systems you can run and harden (DevSecOps).
- **Java Full-Stack + Mobile Applications** — shared REST APIs, auth, real-time data and databases; a Flutter front end on the Java back ends you already build.

## Two things worth knowing

- **Cloud DevOps is the most combinable branch** — its tooling (containers, pipelines, cloud, Linux) sits underneath almost everything else, so it pairs strongly with Java, AI *and* Cybersecurity. If you're unsure of a second branch, it's the most reusable foundation.
- **Video Games is the most self-contained** — Unreal Engine 5, Blueprints and C++ share little tooling with the others. If it's your passion, treat it as a focused single branch, or pair it with anything you love knowing the overlap will be smaller.
