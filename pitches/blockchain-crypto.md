# 🔗 Blockchain & Crypto
**Specialization branch · Zone01 Athens**

> This branch explores the field of blockchain and cryptocurrencies, taking you from transactions, cryptography and smart contracts through to deploying and operating real on-chain systems with Solidity and Ethereum.

## The branch in numbers
| | |
|---|---|
| Format | intensive piscine (~3–4 weeks) + 4 projects |
| Projects | 4 (4 solo · 0 team) |
| Core stack | Solidity, Ethereum, ERC20/ERC721 tokens, Geth/Nethermind nodes, web + wallet integration |

## What you'll build
- A themed ERC721 NFT marketplace with browser- and mobile-wallet connection, on-chain listing and buying, backed by your own server and database.
- Thunder, a layer-2 payment channel node and CLI with off-chain signed states and a challengeable Solidity ERC20 settlement contract.
- benchy, a tool that launches, monitors and benchmarks a five-node multi-client Ethereum network with scenarios and node fault injection.
- An international settlement platform representing stablecoins, dividend shares and bonds as contracts, plus a multi-signature vault asset marketplace.

## You'll learn
- Writing, deploying and testing Solidity smart contracts on local testnets.
- Reasoning carefully about the ERC20 and ERC721 on-chain token standards.
- Designing off-chain signed messages, nonces and channel challenge logic.
- Operating multi-node private networks with Geth, Nethermind and Docker.
- Wiring wallets, web frontends and database servers to blockchains.
- Building multi-signature custody, vaults and cross-asset settlement protocols.

## It's a great fit if…
- You like writing and deploying Solidity smart contracts and reasoning carefully about on-chain token standards.
- You enjoy full-stack work, wiring wallets, web frontends and API or database servers to blockchains.
- You are comfortable running and operating blockchain node infrastructure with Geth, Nethermind, Docker and testnets.
- You are drawn to financial and cryptographic protocol design, from payment channels through settlement to digital signatures.

## References & further reading
New to some of these tools? These are the official docs and starting points for the technologies used in this branch.

- **Solidity** — the smart-contract language. [docs.soliditylang.org](https://docs.soliditylang.org/)
- **Ethereum for developers** — accounts, transactions, EVM. [ethereum.org/developers](https://ethereum.org/en/developers/docs/)
- **ERC-20** — the fungible-token standard. [eips.ethereum.org/EIPS/eip-20](https://eips.ethereum.org/EIPS/eip-20)
- **ERC-721 (NFT)** — the non-fungible-token standard. [eips.ethereum.org/EIPS/eip-721](https://eips.ethereum.org/EIPS/eip-721)
- **Geth (go-ethereum)** — an Ethereum execution client. [geth.ethereum.org/docs](https://geth.ethereum.org/docs)
- **Nethermind** — an alternative Ethereum client. [docs.nethermind.io](https://docs.nethermind.io/)
- **Layer-2 scaling & payment channels** — off-chain settlement. [ethereum.org/scaling](https://ethereum.org/en/developers/docs/scaling/)
- **Docker** — running multi-node networks in containers. [docs.docker.com](https://docs.docker.com/)
- **MetaMask** — browser-extension Ethereum wallet. [metamask.io](https://metamask.io/)
- **WalletConnect** — open protocol for connecting mobile wallets to web apps. [walletconnect.network](https://walletconnect.network/)
