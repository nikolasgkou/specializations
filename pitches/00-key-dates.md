# Specialization piscines — key dates & how to sign up

| | |
|---|---|
| **First Wave** | starts **18 June 2026** |
| **Second Wave** | starts **1 September 2026** |
| **Tell your mentors** | by **Tuesday 16 June** — whether you join the First Wave, and your **two top choices** |
| **Registrations** | open right after Friday's meeting |
| **Minimum to run a piscine** | 6 participants |

**Good to know**

- Every student can take part, regardless of where you currently are in the Rust curriculum.
- All specialization areas are available; piscines are scheduled based on participation.
- If you want to complete **two** specializations, you must start the first one on **18 June** — starting in September will not leave enough time for a second one. See **`combining-specializations.md`** for smart ways to pair two branches.
