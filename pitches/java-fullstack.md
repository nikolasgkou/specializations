# 🧑‍💻 Java Full Stack Development
**Specialization branch · Zone01 Athens**

> This branch explores the use of Java in Full Stack Development along with the discovery of Angular, Postgres, Jenkins, MongoDB, Sonar to build scaled web applications.

## The branch in numbers
| | |
|---|---|
| Format | intensive piscine (~3–4 weeks) + 12 projects |
| Projects | 12 (3 solo · 9 team) |
| Core stack | Java, Spring Boot, Angular, Docker, MongoDB |

## What you'll build
- A from-scratch single-threaded HTTP/1.1 server in pure Java using java.nio non-blocking I/O, with CGI execution and a config file.
- A Neo4j-backed movie recommendation engine with four Spring Boot microservices, OAuth2/JWT security, Cypher graph modeling and an Angular interface with search and watchlist, fully containerized over HTTPS.
- A Spring Boot microservices marketplace with Kafka events, cart, checkout, orders, search and analytics dashboards, fronted by Angular.
- A two-phase capstone Travel Management System over PostgreSQL, Neo4j and Elasticsearch, with Stripe and PayPal payments and centralized logging, provisioned with Docker, Ansible, Jenkins and SonarQube.

## You'll learn
- Backend development with Java and Spring Boot.
- Security with JWT, OAuth2 and role-based access.
- Angular single-page applications with guards and interceptors.
- Microservices, Kafka events and inter-service communication.
- DevOps with Docker, Jenkins, SonarQube, Nexus and Ansible.
- Working across four data stores: MongoDB, PostgreSQL, Neo4j and Elasticsearch.

## It's a great fit if…
- You like backend-heavy work in Java and Spring Boot with real security.
- You want a fullstack path pairing Spring Boot backends with Angular frontends.
- You enjoy DevOps and infrastructure: Docker, Jenkins, SonarQube, Nexus and Ansible.
- You are curious about multiple databases including MongoDB, PostgreSQL, Neo4j with Cypher, and Elasticsearch.
