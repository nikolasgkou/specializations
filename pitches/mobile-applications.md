# 📲 Mobile Applications
**Specialization branch · Zone01 Athens · 6 months**

> This branch explores the field of mobile development through Dart and Flutter. The outcome of the branch is that students can create responsive and performant mobile apps of a various complexity for both iOS and Android operating systems.

## The branch in numbers
| | |
|---|---|
| Format | intensive piscine (~3–4 weeks) + 6 projects |
| Projects | 6 (0 solo · 6 team) |
| Core stack | Dart, Flutter, real-time backends, device sensors & geolocation, Firebase |

## What you'll build
- A fullstack real-time multiplayer chess app with full rule validation and move enforcement, a main menu, waiting room and game board, public games, invites, turn notifications and end-game messaging.
- A real-time stock-trading simulator where each account starts with a wallet of fake dollars, can buy, sell and hold across twenty monitored stocks, view historical data and charts, and watch prices update five or more times per second.
- A cross-platform messenger with biometric login, profiles, user search and QR-code contacts, text, image and video messages with read receipts and typing indicators, message editing and deletion, and end-to-end encrypted secret chats.
- A sensor-driven night-sky map that reads GPS, accelerometer and magnetometer to render planets, the sun, moon and constellations live on a canvas, shifting as you move the phone, with tap-for-info on any object.

## You'll learn
- Build responsive Flutter UIs and smooth animations in Dart.
- Manage app state with BLoC, Provider or MVC.
- Wire real-time backends to mobile frontends.
- Integrate device sensors, GPS and geolocation.
- Implement biometric auth and end-to-end encryption.
- Ship apps for both iOS and Android.

## It's a great fit if…
- You like building polished, interactive mobile UIs and animations in Flutter and Dart.
- You enjoy fullstack work, wiring real-time backends to frontends.
- You are drawn to device hardware: sensors, GPS, cameras and biometrics.
- You care about app security and privacy through encryption and biometric authentication.

## References & further reading
New to some of these tools? These are the official docs and starting points for the technologies used in this branch.
