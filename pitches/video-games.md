# 🎮 Video Games
**Specialization branch · Zone01 Athens**

> This branch explores the field of video games, using Unreal Engine 5 (Epic Games) as a foundation. Students will work on game design, game development, and game engine functioning and development.

## The branch in numbers
| | |
|---|---|
| Format | 10 projects (no piscine) |
| Projects | 10 (5 solo · 5 team) |
| Core stack | Unreal Engine 5, Blueprints, C++, Behavior Trees, Networking & Replication |

## What you'll build
- A first-person portal puzzle game with two active portals, physics-preserving traversal, and custom post-process rendering.
- An online multiplayer racing game replicating vehicle physics for up to four players, with a lobby, ready-up, in-game chat, and a checkpoint race mode.
- A wave-based survival game driven by behavior-tree AI hordes, with an economy, upgrades, and dynamic spawning.
- A melee combat system built on your locomotion engine, with weapon movesets, hit detection, and combat AI.

## You'll learn
- Gameplay programming in Unreal Engine 5 with Blueprints and C++.
- Animation systems: state machines, blend spaces, aim offsets, inverse kinematics.
- Behavior-tree AI for patrol, detection, hordes, and combat.
- Server-client networking and replication for multiplayer play.
- Physics systems for vehicles, projectiles, and portal traversal.
- Decoupled architecture using event dispatchers and modular actor components.

## It's a great fit if…
- You want to specialize deeply in Unreal Engine 5 and ship complete, playable games.
- You enjoy gameplay programming across locomotion, combat, vehicles, AI, and puzzle mechanics.
- You like working with both Blueprints and C++ and care about clean, decoupled architecture.
- You are drawn to animation, state machines, physics, and the feel of player movement.
